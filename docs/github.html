Tự build từ mã nguồn

Hướng dẫn build và sử dụng chi tiết (song ngữ Việt/Anh) nằm ngay trong README của repo. Tóm tắt: 

cargo build --release -p vietzip   # core engine + CLI
cd apps/desktop && npm install && npm run tauri build   # ứng dụng desktop
